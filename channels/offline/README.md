# offline · 离线（约定态）

## 一、方式定义
**不联网**：全部方式（direct/pin/mirror/cdn/hosts）失败后的**约定态**——无实现文件、无网络行为，只是路由链的诚实终点。

## 二、适合的情况
所有情况链耗尽时：给出离线预置（本地已有缓存的位置）与人工指引（如：手动下载后把文件放到哪里、把仓库 zip 放到哪个目录）。

## 三、内部降级链（细粒度）
无（终端态）。链尾出口的输出承诺：**不假装成功**——如实报告失败原因（`tried[]` 全程留痕）+ 给出"人还能做什么"。

## 四、前提与副作用 / 红线
零网络、零系统改动。禁止编造"取到了"。

## 五、实测记录
约定态自始存在（`routes.json` 各场景链尾节点；`routes --check` 校验其存在）。
